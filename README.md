# CHINAR Food Fight — Ночная смена · v2

Локальный браузерный пиксельный платформер для кофейни. 2–12 игроков в комнате, вход по ID. На главном экране одна игра. Все графика и звук генерируются локально, внешних ресурсов и npm-зависимостей нет.

**Первичная установка на Windows:** откройте `УСТАНОВКА-СЕРВЕРА-WINDOWS.txt` в этой папке. Там описаны установка на компьютер с FusionPOS, запуск, подключение телефонов, постоянный IP и решение проблем.

## Установка Windows одним запуском

Распакуйте полный архив **chinar_game-windows-installer.zip**, дважды нажмите **УСТАНОВИТЬ.cmd**. Node.js включён, интернет и ручная установка зависимостей не нужны. На рабочем столе появится ярлык **Чинар — сервер**. Отдельное нативное окно Windows с кнопками «Старт сервера», «Стоп сервера», «Открыть игры» показывает адреса и журнал и позволяет сменить порт. Браузер для управления открывать не нужно. При первом разрешении сети Windows может запросить администратора. Сама установка — в профиле текущего пользователя.

Полная инструкция: **НАЧНИТЕ-ЗДЕСЬ.txt** и **УСТАНОВКА-СЕРВЕРА-WINDOWS.txt**. Установщик рассчитан на Windows x64/ARM64; его нативная часть требует проверки на Windows. Существующий запуск на Mac сохранён.

## Быстрый запуск исходников

Установите поддерживаемую Node.js LTS с https://nodejs.org/en/download/ .
Windows: дважды нажмите `start-windows.bat`.
macOS/Linux: в папке игры выполните `node server.js`.
Локально откройте http://localhost:3000 . На других устройствах используйте IP, напечатанный сервером. Для другого порта задайте переменную окружения PORT.

## Матчи

Создатель выбирает режим и лимит: **1, 3, 5 или 10 минут**. Эти настройки общие для всей комнаты.

- **Больше фрагов:** после поражения возрождение через 2,2 секунды. Каждый фраг даёт одно очко. По таймеру побеждает игрок с наибольшим счётом. При равном счёте — ничья, число поражений победителя не определяет.
- **На выбывание:** одна жизнь. Последний оставшийся игрок побеждает досрочно. Если время вышло, выжившие делят победу. Поздние участники текущего раунда наблюдают до следующего.
- Для старта нужны минимум два игрока. До старта доступна разминка: движение, прыжки, оружие и стрельба без урона. Создатель нажимает «Начать смену», затем идёт трёхсекундный отсчёт, не входящий в лимит матча.
- После результатов через 10 секунд комната возвращается к ожиданию. Создатель запускает следующий матч. Счёт сбрасывается.
- При выходе создателя роль переходит следующему участнику. Вышедший игрок не включается в итоговую таблицу. Если в режиме выбывания остался один активный участник — раунд заканчивается.
- Защита на 1,8 секунды после старта или возрождения. Места появления выбираются с учётом расстояния до других игроков.

## Управление

- A/D или стрелки — движение, Space/W/↑ — прыжок, мышь — прицел, левая кнопка или F — выстрел.
- Короткое нажатие делает прыжок ниже. Есть небольшое окно прыжка после схода с края и буфер нажатия перед приземлением. Платформы пропускают снизу.
- На телефоне: горизонтальная ориентация, две кнопки слева и прыжок/огонь справа. Можно удерживать несколько одновременно. Прицел помогает выбрать противника впереди в пределах 650 единиц и 200 единиц по высоте.
- Меню ☰ и Escape открывают передышку, но сетевой матч продолжается.
- Фри-бластер: бесконечный запас, 17 урона. Бургеромёт: 18 выстрелов, 40 урона. Пиццемёт: 14 залпов, три кусочка по 24 урона. Оружие подбирается на столиках.
- ♫ переключает музыку и эффекты. В фоне звук приостанавливается. Музыка запускается после взаимодействия с кнопкой входа.
- ⛶ запрашивает полноэкранный режим; на iPhone показывает инструкцию установки через Safari. Кнопка «Установить игру» доступна на главном экране. Android предлагает системную установку только когда браузер разрешает её; по локальному HTTP установка приложения не предлагается. На iPhone используйте Safari → Поделиться → На экран Домой.

## Плавность и эффекты

Сервер рассчитывает физику с фиксированным шагом 60 Гц. Состояние передаётся через SSE 30 раз в секунду. Локальное движение предсказывается в браузере и сверяется с сервером; удалённые игроки интерполируются с буфером 80 мс. Отрисовка идёт через requestAnimationFrame. Фон кухни кэшируется. Ограничено число частиц, учитывается prefers-reduced-motion. Есть анимации, отдача оружия, частицы, звуки, лента фрагов и результаты матча.

## Проверка и ограничения

`npm test` — правила матчей, длительности, победа/ничья, поздний вход, возрождение, защита, приватность токенов, прыжки, установка и интеграционный тест двух HTTP/SSE клиентов.
Браузерная проверка: два игрока, вход по ID, старт, результаты, меню, клавиатура, компактное окно. Реальные Windows, iPhone/Android и сеть кофейни ещё требуют проверки на месте. Исполняемые bat-файлы в macOS не проверялись.

Комнаты и счёт хранятся в памяти и сбрасываются при перезапуске. Игрок без команд удаляется через 20 секунд; пустая комната — через минуту. При временном разрыве SSE переподключается; после удаления игроку нужно войти снова.

Это сервер для доверенной локальной сети. Публичное размещение в интернете требует отдельной подготовки. Для установки на HTTPS потребуется настроить HTTPS-развёртывание; текущий сервер обслуживает HTTP. FusionPOS и настройки Windows игра автоматически не изменяет.

## Структура

- server.js — HTTP, комнаты, авторизация игрока и сетевой цикл.
- arena.js — режимы, оружие, попадания, фраги и результаты.
- public/physics.js — общая физика сервера и клиента; physics.js экспортирует её для сервера.
- public/game.js — управление, предсказание, интерфейс и синхронизация.
- public/renderer.js — пиксельная кухня, персонажи, камера, эффекты.
- public/audio.js — процедурная музыка и эффекты.
- public/install.js — установка на главный экран и подсказки.

## Обновление 2.2: комнаты и управление

В текущей игре появились вкладки «Открытые комнаты», «Создать свою» и «По ID». Список обновляется автоматически, есть поиск по названию/ID/имени хозяина и фильтр режима. Карточки показывают заполненность, стадию и таймер матча. В фраги можно войти во время игры; выбывание после старта — наблюдателем. При создании задаётся название и видимость; создатель может переключать видимость до старта. Закрытые комнаты не перечисляются и доступны по известному ID (это не пароль).

Нативное окно сервера использует существующий локальный управляющий процесс. Повторный запуск ярлыка возвращает открытое окно. Закрытие окна не останавливает игру. Для остановки используйте кнопку. Обновление через установщик закрывает старое окно после штатного выключения управляющего процесса.

Управление касаниями вынесено в public/controls.js: глобальное отпускание/отмена, потеря захвата, уход пальца за кнопку, touchend fallback для Safari, сброс на потере фокуса и немедленная отправка нового состояния. Тесты проверяют в том числе отпускание правой стрелки при удержании прыжка.

Новые файлы: room-directory.js (публичный каталог с отбором полей), public/rooms.js (экран комнат), public/controls.js (жизненный цикл касаний), windows/native-panel.ps1 (нативное окно Windows). Для других будущих игр установленное окно управления останется общим; игровые правила и сетевой протокол пока реализованы для одной Food Fight.
